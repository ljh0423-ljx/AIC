### 像素级贴合度验证 (对极端尺寸 bbox 逐一计算框内植被占比)
| bbox 类型 | 数量 | 框内植被占比 mean / median | 植被<10%的可疑框 |

| 过小 (<0.5% 图面积) | 180 | **0.95 / 0.99** | 1 |
| 过大 (>80% 图面积) | 127 | **0.87 / 0.91** | 0 |

**结论**: 即使是最极端尺寸的 bbox,框内也几乎全是真实叶片植被 (mean 0.87~0.95),
说明 bbox 普遍**贴合真实叶片目标**,过小框是多叶图中的远景小叶 (合法),过大框是满幅单叶 (合法)。
仅 **1/3861 (0.026%)** 可疑框 (`train/TRAIN_000072_IMG_3166_*.JPG`, 框内植被仅 4%, 疑似框到背景)。

**bbox 正确率判断: >99%** (结构 0 缺陷 + 像素贴合度极高)。

## ③ Healthy 类别合理性

PlantDoc 命名约定: 纯 `leaf` 结尾 = 健康参考类; 含病害关键词 (scab/rust/spot/blight/...) = 病害类。

| 候选 Healthy 类 | 图片数 | 目标数 | 判断 |
|---|---|---|---|
| Tomato leaf | 72 | 444 | **可作 Healthy** — 类名无病害词, 数量充足 |
| Apple leaf | 91 | 247 | **可作 Healthy** — 类名无病害词, 数量最多 |
| grape leaf | 69 | 220 | **可作 Healthy** — 类名无病害词, 数量偏少但可用 |

**判断**: 三个 `leaf` 类作为 Healthy/正常叶片类别**合理**, 数量足够支撑训练。
建议训练后用混淆矩阵观察这三个健康类是否与对应作物的病害类区分良好
(若个别图实际含轻微病态, 会在混淆矩阵中暴露, 届时再人工复核, 不阻塞 baseline)。
未修改任何类别名称。

## ④ Tomato leaf yellow virus 数据偏置分析

- **图片数 75, 目标数 824** (单图目标均值 ~11, 显著高于其他类)。
- **pHash 近重复检测** (汉明距离 ≤8): 仅 **1 组 (2 张)** 近重复, 涉及 2 张图。
  - `train/TRAIN_000704_tomato-plant-virus-...jpg` 与 `test/TRAIN_000085_TYLCVDFerrinlr.jpg`
  - (注: 这 2 张跨 train/test, 但因本次按主类分层重划分, 已不在同一 split, 无泄露)

**结论**: yellow virus 的 824 目标 **不是由图片重复造成的偏置**, 而是该类图片每张含大量黄化叶片
(病毒病常整株发病, 单图可框 10+ 片叶)。**不存在重复数据偏置**。

**潜在影响**: 单图多目标会使该类对 loss 贡献偏大, 训练时模型可能偏向该类。
**建议**: 训练时启用类别加权 (按 1/freq 或 sqrt) 或采样平衡, 监控该类过拟合。这是训练策略问题, 非数据问题。

## ⑤ grape leaf black rot 小样本分析

- **图片数 64, 目标数 133, 每图均值 2.1 目标**
- split 分布: train=52, val=6, test=6
- 每图目标数: min=1, max=11

**判断**: 属小样本类别, 但**结构完整、三个 split 均有样本**, 可用于 baseline 训练。
- val/test 各 6 张, 评估指标方差会偏大 (mAP 在小类上波动明显)
- 模型对该类 **recall 会偏低**, 需重点关注
- **建议**: baseline 后若该类 recall 不达标, 考虑过采样或 copy-paste 增强 (属于训练阶段, 不改当前数据)

**非阻塞**: 不影响进入 baseline 训练。

## ⑦ 是否建议进入 PP-YOLOE Baseline 训练

### 可以进入 Baseline 训练

**依据**:
1. **结构干净**: 0 空标签 / 0 越界 / 0 极端长宽比 / 0 加载失败
2. **bbox 贴合真实叶片**: 极端尺寸 bbox 框内植被占比 mean 0.87~0.95, 正确率 >99%
3. **无数据泄露**: 已去重 11 组跨 split 重复, pHash 确认 yellow virus 无重复偏置
4. **划分合理**: 8:1:1 分层, 13 类在三个 split 均有样本, seed=2026 可复现
5. **格式标准**: YOLO TXT 归一化标签 + dataset.yaml, 图片/标签 1:1 配对 (916/114/114)

**训练时需关注 (非阻塞)**:
- yellow virus 单图多目标 → 启用类别加权或采样平衡
- grape leaf black rot / Tomato leaf mosaic virus 小样本 → 监控 recall, 必要时过采样
- 3 个健康类与对应病害类的混淆情况 → 用混淆矩阵定位个别误标

**未做且不应在数据阶段做**: 训练模型 / 修改模型 / 加注意力模块 / 数据增强 / 删除原始数据 / 合并分类版 PlantDoc。
