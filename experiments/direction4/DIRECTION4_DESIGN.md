# 方向4 设计方案 — 密集场景置信度校准(Density-Aware Fine-Grained Detection)

- **日期**: 2026-08-15
- **状态**: 设计完成,待用户批准后进入消融(不在此阶段训练/改模型/碰 TEST)
- **数据基础**: A0(方向2 EXIF-Fix best)为正式基准;仅 VAL 评估;TEST 完全封闭;原始数据集不动
- **诊断依据**: `DIRECTION4_DIAGNOSTIC.md` + `d4_diagnostic.json`(11 项统计 + oracle 模拟)

---

## 1. 设计前提(诊断结论的硬约束)

诊断给出五条对设计起决定性作用的证据:

1. **瓶颈 = 分类置信度校准**(机制A 置信度压低 + 机制B 低分区间类别漂移):R@conf0.5=47.1% vs R@conf0.1=97.1%;184 漏检中 99 个"定位+分类都对但分数 0.3–0.5"、81 个"定位对但类错(均在 0.05–0.49)"、仅 4 个完全无检测。
2. **漏检目标的框质量极高**:180 个漏检覆盖的实际 IoU 均值 **0.762 / 中位 0.780**(79 个 ≥0.8),与稀疏正常目标(0.856)相当 → **是纯校准错误,不是定位错误**。
3. **密集图无高置信锚点**:yellow/mosaic/mold 密集图(img92/93/94/88/101 等)全图 **0 个 ≥0.5 检测** → "从高置信邻居传播/统计主导类"的推理侧手段在最难图像里无信号。
4. **推理侧算子实测均难达 oracle**:oracle·重标61 = **+0.019** mAP,但邻居级主导重标 35 框 **-0.007**(过激进),图像级主导重标 3–14 框 **≈0**(过保守);邻居高分传播对 TP/FP 区分度≈0。
5. **总可及空间大**:oracle·全修正180(类别修正+分数 0.55–0.70)= **+0.124~+0.150** mAP。

**推论**:修复方向必须落在**训练侧(改变模型自身的置信度分布)**,推理侧只能做补充。且方案不能是"类别间重分配"(B1 已证 class-weighted VFL 提 Recall 不提 mAP),而必须**直接修正密集目标的目标分数/梯度**。

---

## 2. 三个候选方案

> 全部为针对性设计,不用通用 CBAM/SE;D1 零推理开销、D2 单遍后处理、D3 可选高开销。

### 2.1 方案 D1(主推)— 密集感知 VFL 置信度目标校准(Density-Aware VFL Score-Target Calibration,训练侧,零推理开销)

**唯一变量**:仅修改 VFL 分类损失在**密集训练图**上对**正锚点**的目标分数(gt_score)处理;网络结构、检测头、回归损失(iou/dfl)、数据增强、采样、NMS、推理阈值、optimizer、epoch、batch size、learning rate 全部与 A0 逐字段一致。

**算子定义**(训练期,按图密度条件化):

- 对每张训练图,密度 d = 该图 GT 目标数;d ≥ **D**(D=5,与诊断"密集"定义一致)即为密集图。
- **正锚 gt_score 地板**:密集图中被分配为前景的锚点,其 VFL 目标分改为
  `gt_score' = max(IoU, floor)`,floor = **0.65**。
  - 实证依据:漏检覆盖实际 IoU 均值 0.762 / 中位 0.780 → 0.65 地板**远低于真实框质量**,只纠正"对 0.76 的框只敢报 0.3–0.5"的过度保守,不会把差框推高。
  - 效果:密集图 TP 的目标分整体上移 → 模型学到"拥挤区目标值得高分"(直接对准机制A)。
- **可选变体 D1b(拥挤背景负项降权,单独试验,不并入 D1 主判定)**:密集图中,中心落在任一 GT 框内但被判为背景的锚点,负样本损失权重 ×β(0.5)。
  - 依据:拥挤区背景锚的海量负样本教会模型"不敢肯定";降权后可减少低分区间类别漂移的土壤(辅助机制B)。
  - 作为独立实验,避免破坏 D1 单变量纯度。

**预期收益**:oracle 上界 +0.12~+0.15;现实目标为捕获其中"可校准"部分(估 +0.01~+0.05,以实际 VAL 为准,不做任何先验承诺)。

**风险与缓解**:
- 过度自信伤 precision → 训练期监控密集桶 P/R、smoke test 先验证;
- 地板值若过高会推高坏框 → 地板取 0.65(<实际 IoU 中位 0.78),并可在 TRAIN 上做 0.60/0.65/0.70 敏感性记录(仅 TRAIN,VAL 只做最终评估);
- 失败即如实记录,不调参重试(沿用 B1 纪律)。

**优势**:零推理开销、结构零改动、完全保留 PP-YOLOE+-s 轻量特性;直接对准诊断机制,不是类间重分配。

### 2.2 方案 D2(备份)— 推理侧 簇投票重打分 + 保守重标(Cluster-Vote Re-scoring & Conservative Re-labeling,无训练)

**唯一变量**:对 A0 权重推理输出的候选框(score≥0.1)做后处理;模型/推理流程其余不变。

**算子**:
1. **保守重标**:逐图计算"图像级检测主导类" dom(score≥0.1 的框按分数加权);对 0.3–0.5 带内、类 ≠ dom 且原类在图内支持分 < straggler×dom 的框,重标为 dom。参数(α 主导占比、straggler 阈值)在 **TRAIN 预测上锁定**,锁前验证重标不降低 TRAIN mAP。
   - 目标:捕获 oracle·重标61(+0.019)中的一部分。诊断实测图像级主导过保守(3–14 框,Δ≈0),需在 TRAIN 上精细调参;若 TRAIN 锁定阶段证明无法无损捕获,则**放弃重标**。
2. **簇投票重打分(仅当其通过 TRAIN 验证才启用)**:0.3–0.5 框若同类邻居(score≥0.1,中心距<τ·diag)聚合证据强,则小幅提分 λ(封顶 0.55)。
   - 诊断实测邻居高分传播对 TP/FP 区分度≈0 → **默认高风险,很可能在 TRAIN 验证阶段被弃用**;保留此项仅为完整性,诚实预期不启用。

**预期收益**:乐观 +0.005~+0.015(若重标可无损捕获 oracle 一部分);诚实预期可能 ≈0。

**优势**:零训练,直接叠加在 A0 权重上,可当天出结果;作为 D1 之前的廉价信号与 D1 之后的补充。
**风险**:算子误伤正确检测 → 由 TRAIN 锁定阶段把关。

### 2.3 方案 D3(可选)— 推理侧 TTA + 密度自适应阈值

- TTA(水平翻转 + 2 尺度)稳定密集场景置信度,再按图密度自适应阈值(密集图降阈至 0.3 + 局部孤立 FP 抑制)。
- 推理开销 2–6×,牺牲部分轻量优势;主要改善固定阈值下 R/P/F1,对 mAP 提升有限(COCO AP 阈值无关)。
- **定位**:效率弹性选项,默认不进入正式消融;仅在 D1/D2 之后仍有余量时考虑。

## 3. 推荐决策

| 优先级 | 方案 | 类型 | 推理开销 | 依据 |
|---|---|---|---|---|
| **主** | **D1** 密集感知 VFL 置信度校准 | 训练侧 | **0**(不变) | 诊断实证核心机制;oracle 上限 +0.12~+0.15;零开销完全保留轻量 |
| **备** | **D2** 簇投票重打分+保守重标 | 推理侧 | 单遍后处理 | oracle·重标61 = +0.019;零训练,可作为 D1 前的廉价信号/后的补充 |
| 可选 | D3 TTA+自适应阈值 | 推理侧 | 2–6× | 效率弹性,默认不做 |

**选择理由(对应用户偏好"推理开销低、保留轻量优势")**:
1. D1 把校准烧进权重,**推理零开销**、网络零改动,是最彻底的"保留 PP-YOLOE+-s 轻量"方案;而诊断证明推理侧手段在最难的密集图没有可用信号(§5.4)。
2. D1 与 B1(class 权重)的本质区别:**B1 是类间重分配(已证无效),D1 是直接修正密集目标的目标分数与背景梯度**,对准的是"置信度压低"这个被 5 条证据坐实的机制。
3. D2 作为无训练、可立即验证的廉价方案,先跑一遍(锁参于 TRAIN)给 D1 决策提供补充信号;即便其自身 ≈0,也能帮助确认"推理侧天花板",坚定 D1 必要性。

- **不修改原始数据集 / processed_detection 原文件**(沿用 EXIF-Fix 副本)。
