- 机制验证(2-epoch Smoke): **35/35 机制检查 + 114 批真实批次证据全部 PASS**(见 `d1_smoke/D1_SMOKE_REPORT.md`)。

## 4. 判定与解读

**判定: D1 无效 (FAIL)** —— 依用户预设标准严格判定,不调参、不修改机制、不继续第二轮训练。

- **正面**: 核心假设被证实(密集 Recall +0.138/+0.081,弱类 Recall 全面提升,低置信正确目标减少);mAP 提升 +0.0049,距门槛仅 0.0001。
- **代价**: Precision -0.036、FP +27、定位对但类错 +11,且 3 个强类 AP 回退>0.03。
- **机制解读**: 抬升 dense 正锚目标(0.65 地板)使模型对密集/弱类更"激进"(Recall↑、FP↑、Precision↓),同时对样本多、易分的强类造成一定干扰(AP 回退)。0.65 地板在密集类上的收益未足以覆盖强类损失,总体 mAP 未能跨过 0.4062 门槛。
