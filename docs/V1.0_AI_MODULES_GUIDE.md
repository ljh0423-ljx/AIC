# 智农慧眼 V1.0 — AI 智能诊断模块指南

> 本文档描述在 PP-YOLOE+-m 检测基础上新增的 **VLM / RAG / Agent / 语音问答** 智能模块的配置、架构与运维方法。
> 生成时间：2026-09-21。数据与结论均来自第三阶段（3.1–3.8）实测验证，未虚构。

## 1. 概述

| 模块 | 真实能力 | 后端 | 模型 |
|---|---|---|---|
| PP-YOLOE+-m | 13 类叶部病害/健康检测 | paddle_cpu/gpu | best_model.pdparams |
| VLM 视觉分析 | 读原始图片 + 检测结果，输出可见特征 | DashScope | qwen3-vl-plus |
| RAG 知识检索 | 向量检索农业病害资料，返回可追溯来源 | numpy 本地向量库 | text-embedding-v3 |
| Agent 智能决策 | 受控工具调用，信息性诊断 + 人工复核建议 | DashScope | qwen-plus |
| ASR/TTS | 真实中文语音识别与合成 | SenseVoice / Edge-TTS | — |
| 名称规范化 | 中英文病名/别名 → 标准英文类名 | name_alias | — |

## 2. 环境与依赖

- 操作系统：Windows 11（本地 Web/推理验证）；训练/评估在 AutoDL Linux + RTX 4090。
- Python 3.12；核心依赖见 `inference/requirements_infer.txt` 与 `web/requirements_web.txt`。
- 智能模块额外依赖：`openai>=1.0`（复用 VLM/RAG embedding/Agent），`numpy`（向量库）。
- 说明：本机 Chroma 原生扩展写入向量时崩溃（Segfault），故 RAG 采用纯 numpy 本地向量库（`web/services/vector_store.py`）。

## 3. API 配置（环境变量，密钥不落源码/日志）

| 变量 | 用途 | 默认 |
|---|---|---|
| `DASHSCOPE_API_KEY` | 百炼密钥（VLM/RAG embedding/Agent 共用，**必填**） | — |
| `AGRI_VLM_MODEL` | VLM 模型 | qwen3-vl-plus |
| `AGRI_RAG_EMBED_MODEL` | 向量化模型 | text-embedding-v3 |
| `AGRI_AGENT_MODEL` | Agent 模型 | qwen-plus |
| `AGRI_VLM_BASE_URL` / `AGRI_AGENT_BASE_URL` / `AGRI_RAG_EMBED_BASE_URL` | API 地址 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| `AGRI_VLM_TIMEOUT` / `AGRI_AGENT_TIMEOUT` | 超时(秒) | 60 / 90 |
| `AGRI_RAG_CACHE_MAXSIZE` / `AGRI_RAG_CACHE_TTL` | RAG 缓存容量/TTL | 128 / 300s |
| `AGRI_API_MAX_RETRIES` | 有界重试次数 | 2 |
| `AGRI_RAG_DB_DIR` | 向量库目录 | knowledge/vector_db |

密钥配置（PowerShell，无回显）：
```powershell
$k = Read-Host -Prompt "DASHSCOPE_API_KEY" -AsSecureString
$b = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($k)
$p = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($b)
[Runtime.InteropServices.Marshal]::ZeroFreeBSTR($b)
[Environment]::SetEnvironmentVariable("DASHSCOPE_API_KEY", $p, "User")
$k.Dispose()
```

## 5. 模块架构与数据流

```
图片上传/摄像头 → PP-YOLOE 检测 → severity(规则代理) → VLM(真实) → RAG(真实检索+缓存)
              → Agent(真实 LLM 工具调用) → 结果卡片 / 语音问答(TTS)
麦克风 → ASR(真实) → 名称规范化(name_alias) → 病害知识 RAG + Agent 或 当前图片 gr.State 追问
```

关键模块文件：
- `web/services/vlm.py` / `embedding.py` / `vector_store.py` / `rag.py` / `agent.py` / `name_alias.py` / `speech.py` / `severity.py`
- `web/handlers.py`（事件处理与 gr.State 会话上下文）、`web/ui.py`（Gradio 绑定）
- `tools/build_rag_index.py`（知识库建库）

## 7. 知识库建库与更新

```bash
# 增量构建（去重，自动读 knowledge/notes/*.md 与 sources_manifest.json）
PYTHONUTF8=1 python tools/build_rag_index.py
# 重建
PYTHONUTF8=1 python tools/build_rag_index.py --reset
```
- 笔记：`knowledge/notes/*.md`（英文 + `*_cn.md` 中文资料）；来源清单：`knowledge/sources_manifest.json`（含 source_id/region/pesticide_verified）。
- 索引版本记录 `knowledge/index_version.json`；向量数据 `knowledge/vector_db/`（已 gitignore）。
- 更新笔记后重建，索引版本变化会自动使 RAG 缓存失效。

## 8. 状态标注语义

| 状态 | 含义 |
|---|---|
| 真实 VLM（qwen3-vl-plus）/ 真实向量检索 / 真实 LLM 智能体（qwen-plus） | 真实 API 成功 |
| 缓存复用 | 命中 RAG 缓存（检索结果，不含用户图片/会话数据） |
| mock_fallback / mock模式 | 未配置或索引缺失，明确回退（非真实） |
| no_evidence / healthy_leaf / no_detection | 无充分证据 / 健康叶 / 未检出（不等于确认健康） |
| 调用失败，已回退 Mock | 真实 API 异常，如实标注 |

## 9. 故障排查

| 现象 | 排查 |
|---|---|
| Web 启动报 `'gbk' codec can't decode` | 用 `web\run_web.bat` 或先 `set PYTHONUTF8=1` |
| VLM/RAG/Agent 显示 Mock | 检查 `DASHSCOPE_API_KEY` 是否已设为用户环境变量并重启进程 |
| RAG 检索返回 no_evidence | 检查 `knowledge/vector_db/` 是否已建库、病名是否在别名表中 |
| Agent 显示「调用失败，已回退 Mock」 | 检查网络/密钥/额度；`AGRI_API_MAX_RETRIES` 控制重试 |
| 语音无应答 | 检查麦克风权限、ASR/TTS 状态（页面「ASR状态/TTS状态」） |
| 双会话串用（不应发生） | 会话上下文已用 gr.State 隔离；如复现请查 ui.py 的 session_state 绑定 |

## 10. V1.1 扩展：AI 诊断验收报告

V1.1 在原有【⬇️ 结果下载】页面内（`download_files` 下方）新增【AI 诊断验收报告】板块，由 `web/services/report.py` 实现。

- **复用链路**：报告**只读**当前 `gr.State` 会话上下文（`session_state`），直接复用已生成的 PP-YOLOE 检测结果、原图/检测框图（`orig_path`/`vis_path`）、VLM 视觉分析、RAG 检索内容与来源、Agent 综合建议及各模块真实/Mock/回退状态。**不重新执行检测、不调用任何付费 API**（VLM/embedding/LLM 均不再触发）。
- **报告结构**：编号、生成时间、作物、病害类别、检测置信度、检测框面积代理指标、视觉证据、知识来源、人工复核建议、系统运行状态，并附「系统运行验收 ≠ 病害专业确诊」声明。
- **PDF**：`reportlab` + `C:/Windows/Fonts/simhei.ttf`（SimHei），A4 排版、原图/检测图嵌入、长文本自动换页、知识来源可点击链接。
- **会话隔离与清理**：PDF 存 `web/tmp/reports/`（UUID 命名，已被 `/web/tmp/` gitignore），`report_pdf` 组件随 gr.State 会话隔离；清空/换图时重置报告组件；24h TTL 自动清理，不公开其他会话文件。
- **触发**：`report_btn.click → handlers._generate_report(session_state) → (预览, PDF)`；无有效会话时提示「请先上传图片并完成一次检测」。
