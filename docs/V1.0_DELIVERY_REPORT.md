## 3. 五分钟演示流程

1. （30s）打开 http://127.0.0.1:7860，简介首页徽章（PP-YOLOE+-m / 13 类 / VAL 0.428）。
2. （60s）上传 1 张苹果锈病图 → 点击「开始 AI 检测」→ 展示检测框 + VLM 视觉诊断 + RAG 来源 + Agent 决策。
3. （60s）切到「🌾 农业病害场景」→ 演示 15 张 VAL 案例的 原图 vs 检测。
4. （90s）语音助手：麦克风问「番茄晚疫病怎么防治」→ 展示中文病名规范化 + RAG 检索 + Agent 回答 + 来源链接。
5. （60s）语音追问「这张图片是什么病」→ 展示基于当前会话图片的 gr.State 上下文回答。

## 4. 已知限制

1. **Severity 为检测框面积占比的规则代理指标**，不认定真实感染面积、不据此触发施药。
2. **RAG 资料地域适用性**：英文来源为境外推广机构，中文来源已核实但农药登记/剂量/安全间隔期**未经中国大陆官方核验**，系统不输出具体施药方案。
3. **SO-101 机械臂为 Mock**，不向硬件下发动作。
4. 双浏览器真实并发验证未用 Playwright 执行（采用两个独立 `gradio_client` 会话，符合「独立 Gradio 客户端会话」要求）。
5. 向量库为纯 numpy 实现（Chroma 原生扩展本机 Segfault 的替代方案）。
