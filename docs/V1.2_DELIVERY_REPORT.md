## 2. 八个流程节点（按顺序）

1. 原始图片（含原图缩略图）
2. PP-YOLOE 检测（含检测结果图缩略图 + 检出类别/置信度）
3. 检测框面积代理评估（面积占比 + 严重程度 + 检测框）
4. VLM 视觉分析（可见特征 + 模型名 + 真实/Mock 状态）
5. RAG 知识检索（检索状态 + 缓存/实际检索 + 来源数）
6. Agent 综合建议（建议内容 + 模型名 + 真实/Mock 状态）
7. 语音交互状态（已执行 / 本次未执行）
8. 验收报告状态（已执行 / 本次未执行）

节点间以箭头连接，整体采用与 Web 一致的深色农业科技风格。

## 3. 数据来源

流程图**只读**当前 `gr.State` 会话上下文（`session_state`），直接复用已生成的 PP-YOLOE 检测结果、原图/检测框图（`orig_path`/`vis_path`）、`severity_result`、`vlm_result`、`rag_result`、`agent_decision`，以及 `voice_done`/`report_done` 执行标记。

**不重复执行检测、不调用任何付费 API**（VLM/embedding/LLM 均不触发）。

## 4. 生成与导出方式

- 依赖：`matplotlib`（项目已有依赖，**无新增依赖**）+ 中文字体 `C:/Windows/Fonts/simhei.ttf`（SimHei）。
- 生成：`web/services/flowchart.py` 用 matplotlib 绘制 8 节点流程图，分别导出 PNG（页面预览/下载）与 PDF（下载）。
- 存储：`web/tmp/flowcharts/`（UUID 命名，该目录随 `/web/tmp/` 已被 `.gitignore` 排除），24h TTL 自动清理。
- 会话隔离：导出文件按 UUID 命名，`flow_preview`/`flow_png`/`flow_pdf` 组件随 gr.State 会话隔离；清空/换图时重置，不公开其他会话文件。

## 7. 已知限制

1. 真实浏览器人工验收尚未完成（代码级/独立 Gradio 客户端会话验证）；人工步骤：浏览器打开 http://127.0.0.1:7860 → 上传图片 → 检测 → 切到【🧭 诊断流程图 / 可视化记录图】→ 生成 → 预览/下载 → 换图/清空后确认已清空。
2. 流程图仅覆盖**当前图片**的诊断结果；批量多图以第一张（当前展示）图片为准。
3. 检测框面积占比为规则代理指标，不认定真实感染面积；VLM 为可见特征分析，非病原学确诊。

## 8. 使用说明

1. 上传作物图片 → 点击「开始 AI 检测」完成检测。
2. 切换到【🧭 诊断流程图 / 可视化记录图】→ 点击「🧭 生成诊断流程图」。
3. 查看「流程图预览」；点击「下载 PNG」或「下载 PDF」导出。
4. 更换图片或「清空任务」后，流程图预览与下载入口自动清空。
